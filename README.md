## 01 · The Researcher

Mathematician first, engineer second. I work at the boundary where **formal mathematics meets learned systems** — building models whose behavior I can reason about, not just benchmark. My backend work exists for one reason: **to serve mathematics at scale** without it collapsing under its own assumptions.

```text
Axioms → Proofs → Algorithms → Models → Production
   ▲                                                   │
   └─────────── nothing ships unproven ─────────────────┘
```

> *Friends don't let friends deploy models they can't explain.*
> — overfitting is how the Mind Flayer gets in.

**Core disciplines**

| Domain | What I actually do |
| --- | --- |
| **Mathematics** | Linear algebra, real & functional analysis, probability theory, stochastic processes, optimization, information theory |
| **Machine Learning / AI** | Deep learning (PyTorch), statistical learning theory, representation learning, evaluation methodology, model interpretability |
| **Systems (Backend)** | FastAPI model serving, containerized inference, CI/CD, observability — infrastructure as rigorous as the math it hosts |
