## 01 · About

I build infrastructure that ships and models that think. **DevOps** is where I make things reliable — containers, pipelines, infrastructure as code — and **ML/AI engineering** is where my mathematics background does the talking: data pipelines, evaluated models, and systems served behind FastAPI at scale. Lately I've been wandering into **quant** territory, where probability meets pricing.

```text
Mathematics → Programming → Infrastructure → ML Systems → Production
     ▲                                                            │
     └────────────── the pipeline never stops ────────────────────┘
```

> *A model that can't deploy is just a notebook trapped in the Upside Down.*
