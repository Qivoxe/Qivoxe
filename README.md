## 01 · About

I build for the web and train models that ship. **Frontend engineering** is my strongest skill — polished, responsive interfaces in React — and **machine learning** is where my mathematics background does the talking: data pipelines, scikit-learn models, and models served behind FastAPI endpoints.

```text
Mathematics  →  Programming  →  Frontend Engineering  →  Machine Learning  →  Real Products
```
